    Tables and views

    This is a real SQLite engine running in your browser. You can SELECT, INSERT, UPDATE, DELETE, CREATE, ALTER, DROP, use transactions, triggers and views. Changes stay in your browser (not on the server) until you hit Reset.

    About this project

    Oil Leaks Database is an open-source, relational dataset of oil spills and leaks around the world, covering tankers, pipelines, offshore platforms, wells, storage facilities and rail on land, freshwater and the sea. It was started as a DBMS course project and is built so anyone can use, query and improve it.

    Data quality

    The seed dataset is a curated set of well-known incidents compiled from public sources. Volumes are approximate (see the volume_confidence column), coordinates mark the approximate location, and estimates for many historical spills vary between sources. Please verify against primary sources before citing, and send corrections as pull requests.

    Get the data

    Contribute

    Add rows to the CSV files in data/ and open a pull request. A validation script checks foreign keys, dates and coordinates automatically. Code is MIT licensed and the dataset is CC BY 4.0.
